# 📱 iOS Login & Registration

[![Swift Version](https://img.shields.io/badge/Swift-5.10-orange.svg)](https://swift.org)
[![Platform](https://img.shields.io/badge/Platform-iOS%2015%20%2B-blue.svg)](https://developer.apple.com/ios/)
[![UIKit](https://img.shields.io/badge/Framework-UIKit-red.svg)](https://developer.apple.com/documentation/uikit)

A native iOS mobile application implementing a complete and secure user authentication flow. This project demonstrates best practices in software architecture, real-time data validation, and hierarchical navigation management using native containers.
